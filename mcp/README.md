# MCP-Server

Je MCP-Server ein Unterordner. Geplant:

| Ordner | Zweck | Kommt in |
|---|---|---|
| `adt/` | ABAP entwickeln über ADT: Workspace, prüfen, speichern, aktivieren, testen | Phase 3 |
| `stellvertreter-sap/` | Simulierter SAP-MCP für die Entwicklung auf dem Privatrechner | Phase 1, Schritt 2 |
| `stellvertreter-jira-confluence/` | Simulierter Jira/Confluence-MCP für die Entwicklung auf dem Privatrechner | Phase 1, Schritt 2 |

Die echten Server (Jira/Confluence, SAP-MCP) liegen nicht in diesem Repo; sie werden in der App
mit ihrem Startbefehl eingetragen.
